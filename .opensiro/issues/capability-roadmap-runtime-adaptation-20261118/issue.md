## What could Gas Town do that it cannot do now?
A **Deacon future-runtime patrol wisp** could read a dated external agent-runtime compatibility notice, compare it to Gas Town's actual AgentPresetInfo hooks/resume/compaction settings, choose **stay / one authorized canary / rollback**, dispatch a *new* task session using gt sling --agent, observe its Witness/doctor result, and report the outcome to Mayor before changing later role selection. Never switch a running session or override the Overseer's list of allowed providers.

This is an opt-in original-native **construction hypothesis** using existing patrol, Beads, config and session infrastructure—not a generic VSM controller. It is not implemented and has no measured benefit.
